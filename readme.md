# Optimizing Generation and Storage Dispatch in ERCOT

Course project for MIT 15.C57 – Optimization Methods. We model generation and battery storage dispatch on the ERCOT (Texas) grid as an optimization problem to meet electricity demand at minimum cost.

## Data

Located in `Data Processing/Data/`:

- **Generator_Y2025.csv** – EIA-860 generator data
- **Plant_Y2025.csv** – EIA-860 plant data
- **Native_Load_2025.csv** – ERCOT hourly load by weather zone
